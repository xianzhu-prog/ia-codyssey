# 스터디 모임 

## 대상 사용자

- 함께 취업 또는 공부를 하기 위한 나와 스터디 인원들. 캘린더 형태의 웹 페이지에서 함께 스터디 모임 날짜와 장소 및 내용을 정하고 공유합니다.

## 사용 목적

- 캘린더 형태의 페이지에 되는 날짜를 체크하고, 모일 수 있는 장소 등을 한눈에 확인할 수 있습니다. 또한 메모 등을 남겨 그날의 모임 목적 등을 기록합니다. 

## 화면 구성과 동작

- 맨 위에 스터디 모임의 제목과 설명을 입력할 수 있고, 입력이 되면 아래에 스터디 모임 제목과 설명이 나타납니다.
- 확정된 스터디 날짜가 날짜 순서대로 최대 3개가 보입니다.
- 확정된 날짜를 누르고 옆에 [날짜 취소하기] 버튼을 클릭하면 해당 날짜가 취소되고 확정된 날짜에 보이지 않습니다. 
- 오늘을 기준으로 확정된 스터디 날짜가 며칠 남았는지 확인할 수 있습니다.
- 확정된 스터디 날짜에는 내가 체크한 날짜와 그렇지 않은 날짜가 분리되어 표시됩니다. 
- 이번달 캘린더가 보이고, 오늘 날짜가 표시되어있습니다. 
- 확정된 스터디 날짜도 캘린더에 구분되어 표시됩니다.
- 캘린더 옆에는 [내 일정 추가] 버튼이 존재합니다.
- [내 일정 추가] 버튼을 누르면 새로운 팝업창에서 날짜를 입력할 수 있으며, 
추가한 일정 리스트가 보입니다. 추가한 일정들은 삭제 버튼을 통해 삭제가 가능합니다.  
- 캘린더 날짜를 누르면 캘린더 아래에 해당 날짜에 가능한 인원과 장소, 메모 등을 확인할 수 있습니다. 장소와 메모는 우선 누구나 수정이 가능하며, [날짜 확정하기] 버튼을 클릭하면 확정된 날짜가 됩니다. 

## 필요한 자료

- 스터디모임 제목, 설명, 오늘 날짜, 확정된 날짜, 모임이 가능한 사람, 모임 장소
 

## 완료 기준
- 맨 위에 스터디 모임 제목과 설명을 입력하는 칸이 각각 있고, 해당 칸들에 내용을 입력하면 아래에 제목과 설명이 담긴 문구가 그대로 출력됩니다. 입력 칸에 제목과 설명을 수정하면 문구도 함께 수정됩니다. 
- 확정된 날짜에는 날짜 순서대로 최대 3개가 출력되고 [더보기]를 누르면 확정된 날짜를 모두 다 출력됩니다. 확정된 날짜 옆에는 오늘을 기준으로 디데이 며칠 남았는지 적혀있습니다. 
- 확정된 날짜를 클릭하고 [날짜 취소하기] 버튼을 누르면 해당 날짜가 취소되고, 확정된 날짜 칸에서 해당 날짜가 삭제됩니다.
- 확정된 스터디 날짜에서 내가 체크한 날짜는 초록색 바탕으로, 그렇지 않은 날짜는 회색 바탕으로 구분되어 표시됩니다.
- 캘린더는 오늘 날짜가 표시되어있고, 확정된 날짜도 다른 색깔로 표시되어있습니다. 
- 캘린더 옆 [내 일정 추가] 버튼을 클릭하면, 새로운 팝업창이 나오며 해당 팝업창에는 날짜를 입력하는 칸과 내가 입력한 날짜들이 리스트로 보입니다. 입력한 날짜들은 옆에 [x]버튼을 통하여 삭제 가능합니다. 
- 캘린더 아래부분에는 캘린더에서 선택한 날짜에 대한 정보가 나오는데, 해당 날짜에 선택한 인원과 장소, 메모 등을 확인할 수 있습니다. 장소와 메모는 누구나 수정가능합니다. [날짜 확정하기] 버튼을 클릭하면 해당 날짜가 확정된 날짜가 됩니다. 
- 같은 브라우저에서 열면 해당 내용이 그대로 저장되어 있습니다.
- 페이지 맨 아래에는 [초기화] 버튼이 있고 해당 버튼을 클릭하면 모든 내용이 초기화 됩니다.  
- (꼭 지켜야 할 조건. 예: 다른 파일이나 로그인 없이 HTML 파일 하나로 열립니다)

## 추가 기능

- 이후에는 해당 페이지를 보기 위해서 비밀번호를 입력하는 페이지가 먼저 나옴.

## 한계 및 비목표

1. 모임은 최대 5명까지 가능합니다. 가능한 사람 입력 시 5명까지 가능합니다.
2. 달력은 지나간 날짜에 대해서는 수정이 불가능합니다. 
3. 캘린더는 2027년까지만 볼 수 있습니다. 

## 검증 방법

- 캘린더에서 오늘 날짜가 잘 체크되어있는지, 오늘을 기준으로 디데이가 잘 표시 되는지 확인합니다. 예를 들어 오늘이 11/11이고 확정된 날짜가 11/12라면 확정된 날짜에서 11/12는 d-1로 표시됩니다.
