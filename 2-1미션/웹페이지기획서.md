# 모임픽 (MoimPick)

## 대상 사용자

-   취업 준비를 함께하는 스터디 구성원
-   자격증이나 어학 시험을 준비하는 사람들
-   개발, 데이터 분석 등 특정 분야를 함께 공부하는 사람들
-   정기적으로 오프라인 또는 온라인 모임을 갖는 소규모 그룹

이미 구성된 스터디의 한 사람이 모임을 생성하고, 공유 링크를 다른
구성원에게 전달하여 함께 일정을 정하는 방식이다.

## 사용 목적

스터디 구성원들이 각자 가능한 날짜와 장소를 조율하고, 최종 모임 일정을
확정하고 공유하기 위한 웹페이지이다.

-   모임장이 우선 후보 날짜를 등록한다.
-   구성원들은 캘린더에서 가능한 날짜를 복수 선택한다.
-   구성원들도 새로운 후보 날짜를 추가할 수 있다.
-   날짜별 참여 가능 인원을 취합하여 가장 많은 인원이 가능한 날짜를
    확인한다.
-   모임장과 구성원 모두 장소를 제안하고 투표할 수 있다.
-   최종 확정된 날짜와 장소를 공유하고 관리한다.

## 화면 구성과 동작

### 1. 메인 화면

-   모임 생성하기
-   공유 링크로 참여하기

### 2. 모임 생성 화면

-   모임 이름 입력 (필수)
-   모임 소개 및 목적 입력 (선택)
-   모임장 이름 입력 (필수)
-   캘린더에서 후보 날짜 복수 선택
-   장소 후보 등록 (선택)

### 3. 일정 참여 화면

-   이름 입력 후 참여
-   캘린더에서 가능한 날짜 복수 선택
-   새로운 후보 날짜 추가
-   선택한 날짜 수정 및 취소
-   모임장과 구성원 모두 장소 제안 가능
-   제안된 장소에 투표

### 4. 결과 화면

-   날짜별 참여 가능 인원 표시
-   날짜별 참여자 목록 확인
-   가장 많은 인원이 가능한 날짜 강조
-   장소별 투표 결과 표시
-   최종 날짜와 장소 확정
-   확정 일정 공유

### 5. 확정 일정 관리

-   월별 확정 일정 목록 확인
-   월별 달력에서 확정 날짜 구분
-   누구나 후보 날짜의 \[확정\] 버튼을 눌러 일정 확정 가능
-   확정된 날짜의 \[확정 취소\] 버튼 제공
-   확정 취소 시 후보 날짜로 복귀
-   월별 미진행 확정 일정은 최대 5개까지 허용
-   날짜가 지나면 자동으로 완료 처리하고 지난 모임 내역으로 이동
-   완료된 일정은 월별 최대 5개 제한에서 제외
-   완료 또는 취소된 일정이 생기면 새로운 일정 확정 가능

## 필요한 자료

  구분          필요한 데이터
  ------------- --------------------------------------------------
  모임 정보     모임명, 소개, 모임장 이름
  참여자 정보   참여자 이름
  날짜 정보     후보 날짜, 참여 가능 여부
  장소 정보     장소명, 주소, 설명, 제안자
  투표 정보     날짜별 참여 인원, 장소별 투표 수
  최종 결과     확정 날짜, 확정 장소
  일정 상태     후보, 확정, 완료, 취소
  저장 데이터   모임 정보, 참여자별 선택 내역, 투표 및 확정 결과

## 완료 기준

-   모임장이 모임을 생성하고 공유 링크를 만들 수 있어야 한다.
-   참여자가 이름을 입력하고 모임에 참여할 수 있어야 한다.
-   모임장과 참여자가 캘린더에서 후보 날짜를 추가하고 복수 선택할 수
    있어야 한다.
-   날짜별 참여 가능 인원과 참여자 목록이 정확하게 집계되어야 한다.
-   구성원들이 장소를 제안하고 투표할 수 있어야 한다.
-   날짜별 참여 인원과 장소별 투표 결과를 확인할 수 있어야 한다.
-   누구나 원하는 날짜의 \[확정\] 버튼을 눌러 모임 날짜를 확정할 수
    있어야 한다.
-   월별 미진행 확정 일정은 최대 5개까지 가능해야 한다.
-   확정된 날짜는 별도의 확정 일정 영역에서 확인할 수 있어야 한다.
-   확정된 날짜의 \[확정 취소\] 버튼을 누르면 확정 상태가 해제되어야
    한다.
-   날짜가 지나면 자동으로 완료 처리되어야 한다.
-   완료된 일정은 월별 확정 가능 개수에서 제외되어야 한다.
-   확정 및 취소 결과가 화면에 즉시 반영되어야 한다.
-   브라우저의 localStorage에 데이터를 저장하여 새로고침하거나 다시
    접속해도 데이터가 유지되어야 한다.
-   별도의 서버나 로그인 없이 HTML 파일 하나로 실행할 수 있어야 한다.

## 추가 기능

1.  월별 달력에서 확정된 날짜를 색상으로 구분
2.  날짜별 참여 인원을 막대그래프로 시각화
3.  참여자별 선택 날짜를 확인할 수 있는 기능
4.  확정된 일정의 월별 목록 및 요약
5.  참여자별 일정 선택 내역 수정 기능

## 한계 및 비목표

1.  별도의 서버나 데이터베이스 없이 구현하며, 실제 여러 기기 간 데이터
    동기화는 지원하지 않는다.
2.  회원가입, 로그인 및 사용자 인증 기능은 구현하지 않는다.
3.  공유 링크를 통한 실제 외부 사용자 간 실시간 참여 및 투표 기능은
    구현하지 않는다.
4.  지도 API를 통한 장소 검색 및 위치 확인 기능은 구현하지 않는다.
5.  카카오톡, 이메일 등을 통한 자동 알림 및 초대 메시지 발송은 구현하지
    않는다.

**추가 구현 조건** - 브라우저의 localStorage를 활용해 데이터를
저장한다. - 같은 브라우저에서 재접속하거나 새로고침해도 데이터가
유지되어야 한다. - 브라우저 저장 데이터를 삭제하면 기존 데이터도 사라질
수 있다.

## 검증 방법

-   모임 생성 후 입력한 정보가 정확하게 표시되는지 확인한다.
-   여러 명의 이름으로 날짜를 선택하고 참여 인원이 정확하게 집계되는지
    확인한다.
-   날짜를 추가하거나 취소했을 때 결과가 정상적으로 변경되는지 확인한다.
-   장소 제안과 투표 결과가 정확하게 반영되는지 확인한다.
-   월별 미진행 확정 일정이 5개를 초과하지 않는지 확인한다.
-   모임 날짜가 지나면 자동으로 완료 처리되는지 확인한다.
-   완료된 일정이 월별 확정 가능 개수에서 제외되는지 확인한다.
-   확정 취소 시 확정 일정 목록에서 사라지고 다시 후보로 표시되는지
    확인한다.
-   월을 변경했을 때 해당 월의 일정만 표시되는지 확인한다.
-   새로고침 및 브라우저 재실행 후 데이터가 유지되는지 확인한다.
-   날짜별 참여 인원 그래프가 실제 투표 데이터와 일치하는지 확인한다.
