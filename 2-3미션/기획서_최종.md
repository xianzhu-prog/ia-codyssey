# 모임픽 (MoimPick) 최종 웹페이지 기획서

## 1. 대상 사용자

-   취업 준비를 함께하는 스터디 구성원
-   자격증이나 어학 시험을 준비하는 사람들
-   개발, 데이터 분석 등 특정 분야를 함께 공부하는 사람들
-   정기적으로 오프라인 또는 온라인 모임을 갖는 소규모 그룹

이미 구성된 스터디의 한 사람이 모임을 생성하고, 공유 링크를 다른 구성원에게 전달하여 함께 일정을 정하는 방식이다.

## 2. 사용 목적

스터디 구성원들이 각자 가능한 날짜와 장소를 조율하고, 최종 모임 일정을 확정하고 공유하기 위한 웹페이지이다.

-   모임장이 우선 기본 정보와 후보 날짜를 등록한다.
-   구성원들은 캘린더에서 가능한 날짜를 복수 선택한다.
-   구성원들도 새로운 후보 날짜를 추가할 수 있다.
-   날짜별 참여 가능 인원을 취합하여 가장 많은 인원이 가능한 날짜를 막대그래프로 시각화해 확인한다.
-   모임장과 구성원 모두 장소를 제안하고 투표할 수 있다.
-   최종 확정된 날짜와 장소를 공유하고 관리한다.
-   확정된 일정 중 불필요하거나 취소된 모임은 확정 일정 관리 페이지에서 손쉽게 삭제할 수 있다.

## 3. 화면 구성과 동작

### 3.1. 내 모임 목록 (메인 화면 / 대시보드)
-   현재 진행 중이거나 확정/완료된 내 모임 카드 목록 표시
-   모임 카테고리 (취업/면접, 개발/IT, 자격증/어학, 기타 모임) 태그 및 상태 표시 (일정 조율 중, 일정 확정됨, 완료된 모임)
-   '새 모임 생성하기' 버튼을 통한 생성 화면 이동

### 3.2. 모임 생성 화면
-   모임 이름 입력 (필수)
-   모임장 이름 입력 (필수)
-   모임 카테고리 선택 (취업/면접, 개발/IT, 자격증/어학, 기타)
-   모임 소개 및 목적 입력 (선택)
-   미니 캘린더를 이용한 후보 날짜 복수 선택 (필수)
-   장소 후보 등록 및 태그 삭제 기능 (선택)

### 3.3. 모임 상세 및 투표 화면
-   **일정 투표 & 참여 탭**
    -   참여자 이름(닉네임) 입력 및 설정 기능
    -   후보 날짜별 참여 가능 여부 터치/클릭 선택 (복수 선택 가능)
    -   새로운 후보 날짜 제안 및 추가 기능
    -   장소 후보 제안 및 좋아요/투표 기능
    -   참여자별 선택 날짜 및 참여 현황 실시간 리스트
    -   참여 설정 초기화 버튼 (내 참여 정보 일괄 삭제)
-   **투표 결과 & 확정하기 탭**
    -   최다 참여 가능 날짜 하이라이트 배너 및 선택 폼 (1개 이상, 한 달 최대 5개 선택 가능)
    -   날짜별 참여율 및 인원 막대그래프 시각화
    -   장소 투표 집계 순위 (1위 장소 하이라이트)
    -   선택된 날짜로 일정 확정 처리 기능

### 3.4. 확정 일정 관리 화면
-   월별 달력 뷰: 확정 모임(색상 태그) 및 완료된 모임 표시
-   확정 일정 목록: 해당 월의 확정/완료된 모임 카드 상세 리스트
-   **모임 삭제 기능**: 확정 일정 목록 카드의 '상세보기' 버튼 왼쪽에 `[모임삭제]` 버튼 배치
    -   `[모임삭제]` 클릭 시 "정말로 삭제하시겠습니까?" 컨펌 알림창(confirm window) 출력
    -   `[취소]` 클릭 시 삭제 동작 취소
    -   `[확인]` 클릭 시 대시보드, 확정 일정 목록, 달력 등 전체 앱 시스템 및 localStorage에서 해당 모임 완전 삭제

## 4. 필요한 데이터 구조

| 구분 | 필요한 데이터 |
| :--- | :--- |
| **모임 정보** | 모임 ID, 모임명, 카테고리, 모임장 이름, 모임 소개, 생성일자, 모임 상태(PENDING, CONFIRMED, COMPLETED) |
| **참여자 정보** | 참여자 닉네임, 참여자별 선택한 가능 날짜 목록 |
| **날짜 정보** | 후보 날짜 목록, 확정된 날짜 목록(배열) |
| **장소 정보** | 장소 ID, 장소명, 설명/주소, 장소별 투표 참여자 닉네임 목록 |
| **투표 정보** | 날짜별 가능 인원수, 장소별 득표수 |
| **최종 결과** | 확정 날짜(최대 5개/월), 확정 장소 |
| **저장 데이터** | 전체 모임 객체 배열, 현재 선택된 모임 ID, 현재 활성화된 사용자 닉네임 (localStorage 저장) |

## 5. 완료 및 구현 기준

-   모임장이 모임을 생성하고 공유 링크를 만들 수 있어야 한다.
-   참여자가 이름을 입력하고 모임에 참여할 수 있어야 한다.
-   모임장과 참여자가 캘린더에서 후보 날짜를 추가하고 복수 선택할 수 있어야 한다.
-   날짜별 참여 가능 인원과 참여자 목록이 정확하게 집계되어야 한다.
-   구성원들이 장소를 제안하고 투표할 수 있어야 한다.
-   날짜별 참여 인원과 장소별 투표 결과를 막대그래프와 랭킹으로 확인할 수 있어야 한다.
-   최다 참여 날짜 중 확정할 날짜(한 모임당 월 최대 5개)를 선택하여 일정을 확정할 수 있어야 한다.
-   확정된 날짜는 확정 일정 관리 페이지의 월별 달력과 목록 영역에서 확인할 수 있어야 한다.
-   확정 일정 목록에서 `[모임삭제]` 버튼을 통해 삭제 확인 팝업 후 모임을 데이터베이스 및 화면 전체에서 삭제할 수 있어야 한다.
-   지난 일정은 날짜 체크를 통해 자동으로 완료(COMPLETED) 처리되어야 한다.
-   확정 및 삭제 결과가 UI에 즉시 반영되어야 한다.
-   브라우저의 `localStorage`에 데이터를 저장하여 새로고침하거나 다시 접속해도 데이터가 유지되어야 한다.
-   별도의 서버나 로그인 없이 단일 HTML 파일로 동작해야 한다.

## 6. 추가 기능 및 UI/UX 디테일

1.  **다크모드 & 글래스모피즘(Glassmorphic) UI**: 프리미엄 가독성과 현대적인 어두운 테마 디자인 적용
2.  **모임별 고유 컬러 팔레트**: 확정 일정 달력에서 모임마다 서로 다른 파스텔 색상 뱃지를 적용하여 한눈에 구별 가능
3.  **날짜별 참여율 시각화 막대그래프**: 참여 비율(% 및 인원)에 따른 애니메이션 동적 프로그레스 바 제공
4.  **토스트 알림(Toast Notification)**: 삭제, 확정, 저장, 복사 등 주요 액션 발생 시 하단 팝업 알림 제공
5.  **모임 삭제 기능**: 확정 일정 목록 카드 내 전용 삭제 버튼 제공 및 안전한 2단계 삭제 확인 알림창

## 7. 한계 및 비목표

1.  별도의 백엔드 서버나 DB 없이 브라우저 단독으로 실행하며, 다바이스 간 자동 백엔드 동기화는 지원하지 않는다.
2.  회원가입, 로그인 및 사용자 권한 인증 기능은 구현하지 않는다.
3.  지도 API를 통한 실시간 장소 검색 기능은 포함하지 않는다.
4.  카카오톡, 이메일 등의 외부 서비스 자동 메시지 발송은 포함하지 않는다.

## 8. 검증 방법

-   모임 생성 후 입력한 정보(제목, 모임장, 카테고리, 후보 날짜, 장소)가 정확하게 저장되고 표시되는지 확인한다.
-   여러 명의 이름으로 날짜를 선택했을 때 투표 결과 그래프와 인원수가 올바르게 집계되는지 확인한다.
-   일정 확정 시 해당 월의 달력과 목록에 고유 테마 색상으로 정확히 노출되는지 확인한다.
-   확정 일정 목록에서 `[모임삭제]` 버튼을 눌렀을 때:
    -   경고 알림창("정말로 삭제하시겠습니까?")이 정상적으로 출력되는지 확인한다.
    -   `[취소]` 선택 시 아무 변화 없이 유지되는지 확인한다.
    -   `[확인]` 선택 시 해당 모임이 확정 일정 목록, 달력, 메인 내 모임 목록 등 모든 곳에서 즉시 지워지는지 확인한다.
-   새로고침 및 브라우저 재실행 후에도 수정/삭제된 데이터가 유지되는지 확인한다.

## 9. 최종 변경 및 추가 기능 반영 사항 (v7 기준)

`모임픽_MoimPick(제미나이)_v7.html` 업데이트에 따라 반영된 핵심 변경 내역은 다음과 같습니다.

1.  **[모임삭제] 버튼 기능 추가**
    -   확정 일정 관리 화면의 '확정 일정 목록' 각 카드 하단 영역에 **`[모임삭제]`** 버튼을 추가 (`상세보기` 버튼 좌측).
2.  **안전 삭제 확인 팝업 (confirm window) 연결**
    -   `[모임삭제]` 버튼 클릭 시 브라우저 표준 알림창(`confirm('정말로 삭제하시겠습니까?')`)이 실행됨.
    -   사용자가 `[취소]`를 클릭하면 삭제 처리가 취소됨.
    -   사용자가 `[확인]`을 클릭하면 `deleteMeeting(meetingId)` 함수가 실행되어 중앙 데이터(`appData.meetings`) 및 `localStorage`에서 해당 모임이 영구적으로 제거됨.
3.  **전체 앱 대시보드 & 뷰 실시간 동기화**
    -   모임 삭제 완료 시 '확정 일정 관리'의 월별 달력과 목록뿐만 아니라, 메인 화면 '내 모임 목록' 대시보드에서도 즉시 제거되며, 토스트 알림으로 사용자에게 처리 상태를 안내함.
4.  **기타 기존 UI 및 데이터 안정성 유지**
    -   한 모임 당 월별 최대 5개 확정 날짜 제한 규칙, 자동 완료 처리(COMPLETED) 상태 전환, 모임별 고유 파스텔 컬러 테마 및 반응형 레이아웃을 손상 없이 그대로 유지함.
